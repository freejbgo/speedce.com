SpeedCE

China nationwide nodes · Global nodes · Six detection tools

Free online website & IP speed test platform for webmasters and DevOps. Select a tool from the dropdown, enter a domain or IP, and run tests from China provincial nodes or global nodes. Results appear on interactive maps.

免费在线网站/IP 测速平台。通过下拉菜单选择检测工具，输入域名或 IP，在中国各省市或全球节点发起检测，地图实时展示通畅、异常、检测中与等待状态。无需注册，打开即用。

Detection Tools / 检测工具

  • HTTP Port 80 web availability and response time. 80 端口 Web 服务可用性与响应速度检测。
  • HTTPS Port 443 with SSL/TLS handshake — closest to real browser access. 443 端口加密 Web 服务检测，含 SSL/TLS 握手过程。
  • PING ICMP connectivity and latency from each probe node. ICMP 连通性与网络延迟检测。
  • TCPing TCP port connectivity with custom port — works when ping is blocked. 指定 TCP 端口连通检测，适用于禁 Ping 的服务器。
  • DNS Query A, AAAA, CNAME, MX, TXT, NS records from each node (domain only). 从各节点查询 DNS 记录，支持解析一致性统计（仅支持域名）。
  • Traceroute Hop-by-hop route from a selected node; optional MTR mode for loss and latency stats. 从所选节点进行路由追踪，可选 MTR 模式查看丢包与延迟统计。
