## 快速上手

1. 打开 https://speedce.com/?lang=zh-CN
2. 选择 **中国节点** 或 **全球节点**
3. 在工具下拉菜单选择检测类型（HTTP / HTTPS / PING / TCPing / DNS / 路由追踪）
4. 输入域名或 IP，点击 **开始测速**

## 六种工具速查

| 工具 | 用途 |
|------|------|
| HTTP | 80 端口 Web 可用性 |
| HTTPS | 443 端口 + SSL/TLS |
| PING | ICMP 连通性与延迟 |
| TCPing | 指定 TCP 端口（禁 Ping 时用） |
| DNS | 各节点 DNS 解析一致性 |
| 路由追踪 | 逐跳路径，可选 MTR 模式 |
